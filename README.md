## math_builder

Данный проект реализует графическое приложение для строительства графиков для linux (актуальная версия 1.3.1).

При запуске приложения появится окно с фиксированными размерами. Чтобы построить график, необходимо нажать правой кнопкой мышью на окно ввода, на котором написано "Enter" и после этого ввести туда функцию, после ввода нажать enter. Чтобы построить новый график нужно нужно повторить действия.

## Правила ввода функций
1. Операнды и операторы необходимо разделять пробелами. 
2. Функция начинается с "y = ".
3. При вводе разрешается использовать только следующие операторы: "+", "-", "*", "/", "sin", "cos", "tg", "ln", "(", ")".

## Примеры ввода выражений
y = ( ln x ) / ( sin x )<br>
y = 3 * x ^ 2 + 2 * x + 5<br>

## Возможности
Чтобы изменить масштаб можно использовать колесо мыши. Рядом с курсором пишутся его координаты. 

Чтобы сменичать участок видимости можно использовать стрелочки.

Чтобы увидеть координатную сетку нужно нажать ctrl. Чтобы ее спрятать нужно еще раз нажать ctrl.

Чтобы сбросить выражение, нужно нажать esc.
